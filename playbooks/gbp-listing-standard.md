# Google Business Profile listing standard

[Back to overview](../README.md)

For a brand with many villas, each with its own profile.

| Field | Standard |
|---|---|
| Name | The villa's real name plus the brand, exactly as on the name plate at the gate. No extra keywords |
| Primary category | Villa. Secondary: the closest lodging category |
| Website | The villa's own page, never the homepage. Use the sitemap for the exact URL |
| Phone | One central booking number that Google has approved |
| Hours | Open 24 hours |
| Service area | City plus locality |
| Photos | Real photos only. Cover, entrance, living, dining, kitchen, every bedroom, pool or theatre if there is one. Files named by villa and room |
| Description | 750 characters or less (see below) |

## Description shape

1. Open with the guest's problem: "Planning a birthday for 12 and tired of cramped hotel rooms?"
2. What the villa has, checked on its live page: BHK, guests, pool, theatre, kitchen, parking.
3. One line on the feeling of the stay.
4. A direct answer to a common question: "Yes, the whole villa is private to your group."
5. How to book.

## Upkeep

- Re-check website links every quarter. Pages move.
- Before changing any URL a profile links to, check the profile first.
- Verification needs the name plate and someone on site. Plan it with operations.
- Ask real guests for reviews and reply to every review. No staff reviews.
