## Where each number comes from

| Row | Source |
|---|---|
| Spend, visits, CPC, impressions, calls | The ad platform |
| Bookings, revenue | Booking system: marketing sources only (website and repeat direct), by booking date, cancellations excluded |
| ROAS | Booking system revenue divided by ad platform spend |
| WhatsApp leads, cart abandoners | The lead dashboard. Leave the row out if the number isn't available |

Use "-" for empty cells. Never fill a missing number with a guess.
